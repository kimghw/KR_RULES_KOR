> 기타 기술규칙/적용지침 및 기준 / GC-20-K / 2025 / KO / Guidance

## 제 3 장 구조강도평가

### 제 1 절 구조 모델링

#### 101. 해석 모델 범위 및 구조 모델링

펌프타워 구조물은 리퀴드 돔 커버, 관 부재, 하부 지지부 등으로 구성이 된다(**그림 5** 참조). 관 부재들에 대한 강도 평가를 위해서는 리퀴드 돔 커버와 하부 지지부가 모델에 포함되어야 한다. 리퀴드 돔 커버는 선박의 화물창 해치 코밍부에 연결이 되고 하부 지지부는 내저판에 고정된 또 다른 지지부와 연결이 되는데, 관 부재들의 평가를 위해서는 하부 지지부에 대한 모델만으로 충분하다. 리퀴드 돔 커버와 하부 지지부에 대한 강도 평가는 별도의 모델과 경계 조건에서 평가하여야 한다.

- **1.** 리퀴드 돔 커버와 하부 지지부는 판 요소를 사용하여 모델링하며 요소 크기는 형상을 충분히 표현할 정도이어야 하며 최대 100 mm x 100 mm 사이즈로 한다. 관 부재는 보 요소로 모델링한다.
  관 부재와 리퀴드 돔 커버가 용접되는 부위, 하부 지지부와 관 부재가 접하는 부위들은 판 요소와 보 요소로 모델링되기 때문에 강체 연결(rigid link) 요소를 사용한다.
- **2.** 펌프타워 구조에는 일반적으로 300 시리즈 스테인리스강이 사용된다. 탄성 계수와 열팽창 계수 등 해석에 사용되는 물성치를 **표 1**에 표기하였다(예: 304L 스테인리스강). 온도에 대한 의존성이 있는 탄성 계수와 열팽창 계수는 **표 1**에서 제시한 온도에 대한 값을 이용하여 선형 내삽으로 계산한다.

  | 탄성계수 | 193 GPa (20 °C)<br>203 GPa (-163 °C) |
  | --- | --- |
  | 프아송 비(Poisson's ratio) | 0.3 |
  | 밀도 | 7.85 x 10^-9 ton/mm^3 |
  | 열팽창계수 | -185°C : 1.33 x 10^-5 mm/mm/°C<br>-130°C : 1.39 x 10^-5 mm/mm/°C<br>-70°C : 1.48 x 10^-5 mm/mm/°C<br>-20°C : 1.57 x 10^-5 mm/mm/°C<br>0 ~ 100°C : 1.72 x 10^-5 mm/mm/°C |

### 제 3 절 강도 평가

#### 301. 관 부재

관 부재에 대한 강도 평가는 항복 및 좌굴 등에 대하여 수행한다. 펌프타워에 쓰이는 재질에 대한 실험 자료에 기초한 접근법이 있다면 이를 바탕으로 허용기준을 정해야 한다. 상세 해석이 가능하지 않은 경우, 다음의 식을 이용하여 관 부재의 항복 및 좌굴강도를 평가한다.

- **1.** 축 인장력 및 전단력
  $\sigma _{a _{-} t} \leq \eta _{a} \sigma _{y}$
  $\sigma _{a _{-} t}$ : 인장응력(유한요소해석으로부터 얻어진 값)
  $\eta _{a}$ : 0.9 (직응력의 경우), 0.52 (전단응력의 경우)
  $\sigma _{y}$ : 170 (N/mm^2)
- **2.** 축 압축력
  $\sigma _{a _{-} c} \leq \eta _{a} \sigma _{cr}$
  $\sigma _{a _{-} c}$ : 압축응력(유한요소해석으로부터 얻어진 값)
  $\eta _{a}$ : 0.783 ($\sigma _{el} \leq \sigma _{y}$ 인 경우)
  $0.9 - 0.0827 \sqrt {\sigma _{y} / \sigma _{el}}$ ($\sigma _{el} > \sigma _{y}$ 인 경우)
  $\sigma _{el}$ : 탄성좌굴응력(N/mm^2)으로 다음 식에 따른다.
  $\sigma _{el} =\pi ^{2} E _{} /( \frac{k \ell }{r} ) ^{2}$
  $E$ : 스테인리스강의 탄성계수(N/mm^2)
  $k$ : 1.0 (filling, discharge, emergency pipe 의 경우)
  0.8 (brace, strut 의 경우)
  $\ell$ : 부재의 길이 (mm)
  $r$ : 최소 회전반지름 (mm)으로 다음 식에 따른다.
  $r = \sqrt {I/A}$
  $I$ : 관성모멘트 (mm^4)
  $A$ : 단면적 (mm^2)
  $\sigma _{cr}$ : 임계좌굴응력(N/mm^2)으로 다음 식에 따른다.
  $\sigma _{cr} =\pi ^{2} E _{t} /( \frac{k \ell }{r} ) ^{2}$
  $E _{t}$ : 스테인리스강의 접선계수(N/mm^2)로 다음 식에 따른다.
  $E _{t} =E[1+0.002 \frac{E n}{\sigma _{y}} ( \frac{\sigma _{cr}}{\sigma _{y}} ) ^{n-1} ] ^{-1}$
  $n$ : knee factor 로서 7.2로 한다.
- **3.** 굽힘응력
  $\sigma _{b _{-} act} \leq \eta _{b} \sigma _{b}$
  $\sigma _{b _{-} act}$ : 굽힘응력(유한요소해석으로부터 얻어진 값)으로 다음 식에 따른다.
  $\sigma _{b _{-} act} = M/Z _{e}$
  $M$ : 굽힘모멘트 (N-mm)
  $Z _{e}$ : 탄성단면계수(mm^3)로 다음 식에 따른다.
  $Z _{e} = \left( \pi /64 \right) \left[ D ^{4} - \left( D-2 t \right) ^{4} \right] / \left( D/2 \right)$
  $D, t$ : **그림 6**에 따른다. (mm)
  $\eta _{b}$ : 0.9
  $\sigma _{b}$ : 굽힘강도(N/mm^2)로 다음 식에 따른다.
  $\sigma _{b} =(Z _{p} /Z _{e} ) \sigma _{y}$ ($\sigma _{y} D / \left( E t \right) \leq 0.02$ 인 경우)
  $\sigma _{b} = \left[ 1.038-1.9 \sigma _{y} D/ \left( E t \right) \right] (Z _{p} /Z _{e} ) \sigma _{y}$ ($0.02 <\sigma _{y} D / \left( E t \right) \leq 0.1$ 인 경우)
  $\sigma _{b} = \left[ 0.921-0.73 \sigma _{y} D/ \left( E t \right) \right] (Z _{p} /Z _{e} ) \sigma _{y}$ ($\sigma _{y} D / \left( E t \right) >0.1$ 인 경우)
  $Z _{p}$ : 소성단면계수(mm^3)로 다음 식에 따른다.
  $Z _{p} = \left( 1/6 \right) \left[ D ^{3} - \left( D-2 t \right) ^{3} \right]$
- **4.** 조합 응력(인장과 굽힘 응력)
  $\left[ \sigma _{a _{-} t} /( \eta _{a} \sigma _{y} ) \right] + \left[ \sigma _{b _{-} act} /( \eta _{b} \sigma _{b} ) \right] \leq 1$
- **5.** 조합 응력(압축과 굽힘 응력)
  $\left[ \sigma _{a _{-} c} /( \eta _{a} \sigma _{cr} ) \right] + \left[ C _{m} \sigma _{b _{-} act} / \left\{ \eta _{b} \sigma _{b} (1- \sigma _{a _{-} c} /( \eta _{a} \sigma _{el} )) \right\} \right] \leq 1$ ($(\sigma _{a _{-} c} / \sigma _{cr} )>0.15$ 인 경우)
  $\left[ \sigma _{a _{-} c} /( \eta _{a} \sigma _{cr} ) \right] + \left[ \sigma _{b _{-} act} /( \eta _{a} \sigma _{b} ) \right] \leq 1$ ($( \sigma _{a _{-} c} / \sigma _{cr} ) \leq 0.15$ 인 경우)
  $C _{m}$: 0.85 또는 $1-0.4 \left[ \sigma _{a _{-} c} /( \eta _{a} \sigma _{el} ) \right]$중에서 작은 값
- **6.** 국부 좌굴
  $\sigma _{a _{-} b} \leq \eta _{local} \sigma _{local}$
  $\sigma _{a _{-} b} = \sigma _{a _{-} c} + \sigma _{b _{-} act}$
  $\eta _{local}$ : 0.75 ($\sigma _{local} \leq 0.55 \sigma _{y}$ 인 경우)
  $0.566 + 0.334 \sigma _{local} / \sigma _{y}$ ($\sigma _{local} >0.55 \sigma _{y}$ 인 경우)
  $\sigma _{local}$ : 임계국부좌굴응력으로 다음 식에 따른다.
  $=0.6 E _{t} t/D$

#### 302. 관 결합부

관 결합부는 코드(Chord)와 브레이스(Brace)가 용접되는 부위를 말하며, 형상 및 하중 형태에 따라 T, Y 혹은 K 형태로 분류한다.

- **1.** 관 결합부의 강도는 다음 식을 만족하여야 한다.
  $\left| \frac{F _{A}}{\mu F _{U _{-} A}} \right| + \left( \frac{M _{IPB}}{\mu M _{U _{-} IPB}} \right) ^{2} + \left| \frac{M _{OPB}}{\mu M _{U _{-} OPB}} \right| \leq 1$
  $F _{A}$ : 브레이스 축 하중 (N)
  $M _{IPB}$ : 브레이스 면내 굽힘모멘트 (N-mm)
  $M _{OPB}$ : 브레이스 면외 굽힘모멘트 (N-mm)
  $\mu$ : 안전 계수로 0.9
  $F _{U _{-} A}$ : 브레이스 축 강도(N)
  $M _{U _{-} IPB}$ : 브레이스 면내 굽힘모멘트 강도 (N-mm)
  $M _{U _{-} OPB}$ : 브레이스 면외 굽힘모멘트 강도 (N-mm)
  $F _{U _{-} A} = \frac{\sigma _{y} T ^{2}}{\sin \theta} Q _{u} Q _{f}$
  $M _{U _{-} IPB} 또는 M _{U _{-} OPB} = \frac{\sigma _{y} T ^{2} d}{\sin \theta} Q _{u} Q _{f}$
  $F _{U _{-} A}$ : 브레이스 축 강도(N)
  $M _{U _{-} IPB}$ : 브레이스 면내 굽힘모멘트 강도(N-mm)
  $M _{U _{-} OPB}$ : 브레이스 면외 굽힘모멘트 강도(N-mm)
  $\theta$ : **그림 6**에 따른다.
  $\sigma _{y}$ : **301.**의 **1항**에 따른다.
  $Q _{u}$ : **표 2**로 결정하는 결합부 하중 및 분류에 따르는 강도계수
  $Q _{f}$ : 코드 하중계수로서 다음 식에 따른다.
  $Q _{f} =1- \lambda \gamma A ^{2}$
  $\lambda$ : 0.030 (축 강도인 경우)
  0.045 (면내 굽힘 모멘트 강도인 경우)
  0.021 (면외 굽힘 모멘트 강도인 경우)
  $\gamma$ : **그림 6**에 따른다.
  $A = \frac{\sqrt {\sigma _{nominal _{-} a} ^{2} + \sigma _{nominal _{-} IPB} ^{2} + \sigma _{nominal _{-} OPB} ^{2}}}{\mu \sigma _{y}}$
  $\sigma _{nominal _{-} a}$ : 코드에서의 축방향 공칭응력(N/mm^2)
  $\sigma _{nominal _{-} IPB}$ : 코드에서의 면내 공칭 굽힘응력(N/mm^2)
  $\sigma _{nominal _{-} OPB}$ : 코드에서의 면외 공칭 굽힘응력(N/mm^2)
  $\mu$ : 안전 계수로 0.9

  | 결합부 형식 | 축하중 |   | 굽힘하중 |   |
  | --- | --- | --- | --- | --- |
  | 결합부 형식 | 압축 | 인장 | 면내 | 면외 |
  | K | $(0.5+12 \beta ) \gamma ^{0.2} Q _{\beta } ^{0.5} Q _{g}$ | $(0.65+15.5 \beta ) \gamma ^{0.2} Q _{\beta } ^{0.5} Q _{g}$ | $4.5 \beta \gamma ^{ 0.5}$ | $3.2 \gamma ^{(0.5 \beta ^{ 2} )}$ |
  | T & Y | $(0.5+12 \beta ) \gamma ^{0.2} Q _{\beta } ^{0.5}$ | $(0.65+15.5 \beta ) \gamma ^{0.2} Q _{\beta } ^{0.5}$ | $4.5 \beta \gamma ^{ 0.5}$ | $3.2 \gamma ^{(0.5 \beta ^{ 2} )}$ |

  $Q _{\beta }$ = $0.3/[ \beta (1-0.833 \beta )]$ $\beta >0.6$인 경우
  = 1.0 $\beta \leq 0.6$인 경우
  $Q _{g}$ = $1 + 0.85 e ^{(-4g/D)}$ $g/D \geq 0$인 경우
  $g$ : **그림 6**에 따른다. (mm)
  $\gamma , \beta$ : **그림 6**에 따른다.

#### 303. 리퀴드 돔 커버 및 하부 지지부

- **1.** 유한요소 모델
  리퀴드 돔 커버 및 하부 지지부의 평가는 **101.**보다 상세한 유한요소모델을 사용하여야 한다.
- **2.** 강도 기준
  리퀴드 돔 커버 및 하부 지지부의 강도는 다음 식을 만족하여야 한다.
  $\sigma _{e} \leq \mu \sigma _{y}$
  $\sigma _{e} = \sqrt {\sigma _{X} ^{ 2} - \sigma _{X} \sigma _{Y} + \sigma _{Y} ^{ 2} +3 \tau ^{ 2}}$
  $\sigma _{X}$ : x방향의 응력(유한요소해석으로부터 얻어진 값) (N/mm^2)
  $\sigma _{Y}$ : y방향의 응력(유한요소해석으로부터 얻어진 값) (N/mm^2)
  $\tau$ : 전단응력(유한요소해석으로부터 얻어진 값) (N/mm^2)
  $\sigma _{y}$ : 170 (N/mm^2)
  $\mu$ : 안전 계수로 1.0 ![](images/image7.png)
